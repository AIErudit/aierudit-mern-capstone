# Notice

## Educational starter repository

This repository is the official starter project for the **AIErudit
"Full-Stack Developer With AI" capstone module** at aierudit.com. Learners
fork this repository, work through the capstone instructions (rules file,
FINDINGS.md, fix commits, optional honors blocks), and submit their fork for
instructor review.

The codebase is the **AIErudit Bookshop** — a minimal MERN-stack online
bookstore. It exists to give learners a realistic but small enough surface
area to demonstrate the AI-IDE discipline taught in the course.

## Security disclaimer

**The bugs in this repository are intentional.** They are planted as
learning material for the capstone exercise. Do not deploy this codebase
to production. Do not enter real credit-card numbers or real personal data
into the local seed user account.

If you discover an **unintentional** security issue (i.e. a bug that is
not part of the documented planted set in
`CAPSTONE_INSTRUCTOR_NOTES.md`), please open a GitHub issue describing the
observable symptom — that is itself useful capstone evidence.
